# Storylines

1. **One posting, start to finish** (picked: one worked example is the story a stranger follows). Device: one diagram that grows; form: one frame that rebuilds. A single example posting travels the path scan, match, resume, apply, prep, archive in hairline nodes; at the resume node the model writes "80% across 12 services", the gate strikes it and the traced line replaces it; the form fills and stops at submit; the prep graph fails a gate, rewrites, searches the user's files, asks one question, and lands ready. First 2 s: a feed of postings scrolling in a blueprint well, one row catching brass. Beats: hook (feed) → match → gate → apply → prep loop → compact → claim. Look: Lumen night. Sound: silent (web hero, autoplays muted).
2. **The myth turned over.** An AI-written resume full of confident numbers; each one is traced to a fact or struck through. Type carries the argument, cuts on the beat. First 2 s: "improved throughput by 80%" set huge. Look: Lumen, type only. Sound: a dry click per strike.
3. **The result first.** The finished ready prep file plays, then the camera pulls back through the graph that produced it, node by node, to the posting it started from. First 2 s: "verdict: ready" in brass. Look: Lumen, one continuous take. Sound: low pad.
